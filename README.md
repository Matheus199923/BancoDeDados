# Banco de Dados

Repositório com códigos e exercícios desenvolvidos durante a disciplina de **Banco de Dados**.

## 🗄️ Tecnologias

* SQL
* MySQL

## 📚 Conteúdo

Os códigos foram desenvolvidos durante atividades e trabalhos acadêmicos, envolvendo conceitos de banco de dados e linguagem SQL.

Entre os conteúdos trabalhados estão:

* Criação de bancos de dados
* Criação de tabelas
* Chaves primárias
* Chaves estrangeiras
* Relacionamentos entre tabelas
* Alteração da estrutura das tabelas
* Comandos `CREATE TABLE`
* Comandos `ALTER TABLE`
* Comandos `DROP TABLE`
* Restrições de integridade

* `meusdadossql/` — códigos SQL desenvolvidos durante a disciplina.

## 🎓 Contexto

Projeto desenvolvido como parte das atividades acadêmicas da disciplina de **Banco de Dados** — Sistemas de Informação.
